# Instruções para trabalhar neste projeto

## Memória do sistema

- Antes de iniciar uma tarefa, leia `cérebro.md` na raiz do repositório e confira o código relacionado à tarefa.
- Ao desenvolver uma funcionalidade, corrigir um problema ou mudar uma decisão, atualize `cérebro.md` na mesma entrega. Isso inclui alterações em telas, cálculos, dados, segurança, armazenamento, integrações, arquitetura e testes.
- Atualize as seções afetadas, a data de atualização e o histórico resumido. Não transforme o documento em uma cópia de toda a conversa nem mantenha informações contraditórias ou ultrapassadas.
- Diferencie funcionalidades implementadas, integrações apenas planejadas e verificações pendentes. Registre os testes realmente executados e seus limites; não declare validação visual quando houve apenas teste automatizado ou revisão de código.
- Se encontrar divergência entre o documento e o código, confira a implementação e as instruções mais recentes do usuário, resolva a divergência e atualize o documento. As instruções do usuário têm prioridade.
- Não registre chaves, tokens, senhas, dados reais de pacientes ou outros dados privados em arquivos versionados.
- Consulte também `SEGURANCA-E-PRODUCAO.md` ao trabalhar em dados, permissões, armazenamento, integrações ou publicação.
- Envie alterações ao GitHub quando o usuário solicitar; não trate uma atualização de documentação como autorização para publicar.

Uma tarefa de desenvolvimento só está concluída quando a memória do projeto também estiver atualizada.
